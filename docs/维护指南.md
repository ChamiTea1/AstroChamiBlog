# 茶糜小站 · 维护指南（小白版）

> 目标：不需要懂编程，照着做就能更新博客内容并发布上线。
> 网站部署在 Cloudflare Pages，**只要把修改提交到 GitHub 仓库的 main 分支，网站就会自动更新**。

---

## 方式一：网页上直接改（零安装，推荐起步）

第一次只需要请你（站主）帮对方做一件事：把她的 GitHub 账号加为仓库协作者（GitHub 仓库 → Settings → Collaborators → Add people），她就能在浏览器里编辑。

### 写一篇新文章

1. 打开仓库：<https://github.com/ChamiTea1/AstroChamiBlog>
2. 进入目录 `src/content/blog/`
3. 点右上角 **Add file → Create new file**
4. 文件名填：`文章名.md`（英文小写、用 `-` 分隔，如 `my-first-post.md`）
5. 文件开头粘贴下面的模板，改成自己的内容：

```markdown
---
title: 文章标题
pubDate: '2026-08-20T10:30:00+08:00'
tags:
  - 随笔
categories:
  - 随笔
description: 一句话简介，会显示在首页卡片上。
cover: '/images/主题名/封面图.jpg'
coverPosition: 'right'
---

正文从这里开始，直接写就行。

## 二级标题

- 列表项
- 再一项

**加粗**、*斜体*、[链接](https://example.com) 都支持。
```

字段说明（都是可选的，缺了就用默认值）：

| 字段 | 说明 |
| --- | --- |
| `title` | 文章标题 |
| `pubDate` | 发布时间，格式必须是 `2026-08-20T10:30:00+08:00` 这种（ISO 格式带时区） |
| `tags` / `categories` | 标签和分类，一行一个，前面加 `  - ` |
| `description` | 首页卡片上的简介 |
| `cover` | 封面图路径（建议横版 16:9、宽度 ≥1200px） |
| `coverPosition` | 封面位置：`top` 上下排布；`left`/`right` 左右排布 |

6. 拉到底部，**Commit changes** 里写一句说明（如「新增文章 xxx」），点 **Commit changes**（绿色按钮，直接提交到 main 分支）。
7. 等 1~2 分钟，打开 <https://chami.asia> 就能看到新文章。

### 改已有内容

同样在 GitHub 网页上找到文件 → 点右上角铅笔图标 ✏️ 编辑 → 改完 Commit changes。

**最常改的文件：**

| 想改什么 | 文件位置 |
| --- | --- |
| 随笔（首页碎碎念） | `src/data/essays.json`（新的一条放数组最前面） |
| 友链 | `src/data/friends.json` |
| 书签 | `src/data/bookmarks.json` |
| 相册 | `src/data/masonry.json` |
| 音乐歌单 | `src/data/music.json` |

> 提示：JSON 文件改的时候注意**不要漏逗号、引号**，改完可以先发给她看看再提交。写错了网站会构建失败，但 GitHub 会提示，改回来重新提交就行，不影响已上线的旧版本。

## 方式二：本地编辑 + 预览（能看效果再发布，进阶）

适合写文章配图、想边写边看排版的情况。**一次性安装**（让站主陪着做一遍）：

1. 装 Node.js：<https://nodejs.org> → 下载 **LTS 版（22.x）** → 一路下一步
2. 装 Git：<https://git-scm.com/downloads> → 一路下一步
3. 打开终端（Windows 按 Win 键输入 cmd 回车；Mac 打开「终端」），执行：

```bash
git clone https://github.com/ChamiTea1/AstroChamiBlog.git
cd AstroChamiBlog
npm install
```

以后每次开始维护，先进入项目目录，再启动预览：

```bash
cd AstroChamiBlog
npm run dev
```

浏览器打开 <http://localhost:4321> 就能看到网站，**边改文件边自动刷新**。

改完发布（在项目目录里执行三行）：

```bash
git add -A
git commit -m "说明这次改了什么"
git push
```

等 1~2 分钟，<https://chami.asia> 更新完成。

> Windows 首次 push 会弹 GitHub 登录窗口，用她的 GitHub 账号登录一次即可。
> 如果 `npm install` 或 `npm run dev` 报错，把报错截图发给站主。

## 图片规范（放图必看）

1. 文章配图放进 `public/images/<主题名>/`（如 `public/images/cat/`），文件名用小写英文 + `-`（如 `cat-01.jpg`）。
2. 正文里引用图片用 **绝对路径**：`![描述文字](/images/cat/cat-01.jpg)`，`![ ]` 里的描述一定要写。
3. 单张图超过 4MB 先压缩：在项目目录执行 `npm run compress-images`。
4. 相册一个相册超过 20 张时，放到图床仓库（ChamiTea1/img-bed），用 jsDelivr 链接：`https://cdn.jsdelivr.net/gh/ChamiTea1/img-bed@main/xxx.jpg`。
5. 相册照片发布前注意去掉 GPS 定位信息（隐私）。

## 歌单维护（音乐页）

1. 找歌单 ID：网易云歌单页网址 `https://music.163.com/#/playlist?id=2426530028` 里的 `2426530028` 就是 ID。
2. 在 `src/data/music.json` 里加一条：

```json
{
  "name": "歌单名字",
  "server": "netease",
  "type": "playlist",
  "id": "2426530028",
  "cover": "封面图链接（可省略）"
}
```

3. **不要用 QQ 音乐（tencent）**：公共接口基本播不了。
4. 封面图链接也可以用上面 jsDelivr 图床的图片。

## 常用小功能（正文里可用）

- 提示框：`{% note 内容 %}`
- 折叠块：`{% folding 标题 %} 内容 {% endfolding %}`
- 多图网格：`{% grid %}` `{% endgrid %}`
- 按钮：`{% btn /链接, 按钮文字 %}`

（更多用法见现有文章里的写法，照着抄最稳。）

## 千万不要动的东西

- `src/config.ts` —— 全站配置，动了可能整体样式错乱
- `public/scripts/main.js`、`src/styles/`、`src/components/`、`src/layouts/` —— 代码
- 不确定的文件一律不要动，问站主

## 常见问题

- **提交后网站没变化？** 等 1~2 分钟刷新；还不行就看 GitHub 上提交是否成功。
- **不小心改坏了？** 在 GitHub 网页打开那个文件 → History → 点旧版本 → Restore，或直接找站主回滚。
- **预览页打不开？** 确认 `npm run dev` 还在运行，端口是 4321。
